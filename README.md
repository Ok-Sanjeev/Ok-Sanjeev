### 1. 🤖 AI Data Cleaner

**Python · Pandas · Gemini API · Pydantic**

An AI-assisted data-cleaning project designed to automate parts of the data preparation process using a controlled set of cleaning operations.

**Key Features**

- Ingests CSV files and profiles their contents.
- Detects data-quality issues such as missing values, duplicates, and inconsistent categories.
- Uses a Gemini-powered planner to propose cleaning operations.
- Validates the proposed plan using Pydantic schemas.
- Executes approved operations through a predefined action registry.
- Performs post-cleaning checks and generates cleaned data and reports.

**Current Status:** In progress
